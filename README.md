# t1ktakdev — Developer Portfolio

A privacy-conscious portfolio for open-source projects published at [github.com/t1ktakdev](https://github.com/t1ktakdev).

## Development

This is a no-build static website built with semantic HTML, modern CSS, and vanilla JavaScript.

Start any local static server in the repository directory:

```sh
python -m http.server 8000
```

Open http://localhost:8000/ .

## Privacy

The public repository intentionally contains only the handle **t1ktakdev**. No academic documents, personal email addresses, or identity-bearing metadata belong in source control. Commit authoring is configured *locally* with a GitHub-provided no-reply email.
